## Proyecto

Análisis de hábitos y condición física asociados con niveles de obesidad.

## Dataset

Estimation of Obesity Levels Based On Eating Habits and Physical Condition

## Fuente

UCI Machine Learning Repository

## Descripción

El proyecto tiene como propósito analizar hábitos alimenticios,
características personales y condiciones físicas asociados con
los distintos niveles de obesidad.

El conjunto de datos será utilizado durante las cinco unidades
del recursamiento para realizar preparación de datos, análisis
supervisado, análisis no supervisado y visualización.

## Aplicaciones del proyecto

### Regresión

Estimar una variable continua, por ejemplo el peso, a partir
de hábitos y características seleccionadas.

### Clasificación

Clasificar el nivel de obesidad mediante la variable
NObeyesdad.

### Análisis no supervisado

Identificar perfiles relacionados con hábitos alimenticios
y condición física mediante técnicas de clustering y PCA.

## Estructura del repositorio

- data/raw: dataset original sin modificaciones.
- data/processed: datos limpios y transformados.
- notebooks: análisis y experimentos.
- src: código fuente reutilizable.
- sql: scripts correspondientes al Data Mart.
- modelos: modelos generados durante el proyecto.
- dashboard: archivos relacionados con el dashboard.
- docs: documentación e informes del proyecto.

## Regla de integridad de datos

El contenido almacenado en data/raw deberá conservarse
sin modificaciones. Los datos derivados de procesos de
limpieza o transformación se almacenarán en data/processed.
